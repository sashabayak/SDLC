## 🎯 Назначение

Приложение рассчитывает численность населения мира на заданную пользователем дату на основе модели экспоненциального роста. Проект демонстрирует применение архитектурного паттерна MVC, работу с графическим интерфейсом на Java Swing и организацию сборки через Maven.

**Основные возможности:**

- Ввод даты (день, месяц, год) через диалоговое окно
- Проверка корректности ввода (диапазон значений, существование даты)
- Расчёт численности населения мира по формуле экспоненциального роста
- Отображение результата в главном окне приложения

## 📖 Содержание проекта

### Модель расчёта

| Компонент | Описание | Формула / значение |
|----------|----------|--------------------|
| **Начальное население** | Численность на 1 января 2022 года | 7 950 000 000 |
| **Годовой прирост** | Темп прироста населения | 0.98% (0.0098) |
| **Формула** | Экспоненциальный рост | P(t) = P₀ · e^(r·t) |

**Пояснение:**

- `P₀` — начальное население (7.95 млрд на 2022 год)
- `r` — годовой темп прироста (0.0098)
- `t` — количество лет с 1 января 2022 года до заданной даты

### Архитектура (MVC)

| Компонент | Файл | Ответственность |
|----------|------|-----------------|
| **Model** | `PopulationModel.java` | Расчёт численности, хранение данных, уведомление слушателей |
| **View** | `MainView.java` | Главное окно приложения, отображение результата |
| **View** | `InputDialog.java` | Диалог ввода даты |
| **Controller** | `PopulationController.java` | Обработка ввода, связь Model и View |
| **Точка входа** | `Main.java` | Запуск приложения |

**Структура MVC:**

- Model — `PopulationModel` хранит дату и рассчитанное население, оповещает View через `ModelListener`
- View — `MainView` (главное окно) и `InputDialog` (диалог ввода)
- Controller — `PopulationController` принимает данные из View и передаёт их в Model

### Технологии

- **Swing** — библиотека для GUI
- **Maven** — система сборки
